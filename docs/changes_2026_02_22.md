# Changes 2026-02-22

Summary of the five implemented changes: put-spread alignment, relative CVaR, steadier equity μ, transparency logging, and CM-IEWMA combiner.

---

## (1) Markowitz put sleeve = put spread everywhere

**Goal:** The 3rd risky asset (SPY_PUT) is the same put-spread instrument in all paths: scenario mode, RND forecasts, and realized returns.

- **data/forecasts.py — `compute_rnd_forecasts()`**
  - Put sleeve is now a put spread: long ATM put at `k_atm`, short OTM put at `K_short = round(k_atm * (1 - SCENARIO_PUT_SPREAD_WIDTH))` (or naked put if width = 0).
  - Entry premium: `p_spread_entry = max(p_atm - p_short_entry, MIN_OPTION_MID)` when width > 0; horizon repricing for both legs at t+1 with `T_remain` (sticky-strike IV); spread value at t+1 = `max(P_long_t1 - P_short_t1, 0)`; return = spread_value / p_spread_entry - 1.
  - `ASSET_ORDER` unchanged (`["SPY", "SPY_CALL", "SPY_PUT", "USDOLLAR"]`); SPY_PUT is interpreted as put spread.
  - Diagnostics added: `put_is_spread`, `put_spread_width`, `k_put_short`, `p_spread_entry`, `p_short_entry`.

- **backtest.py — `build_realized_returns()` and `build_realized_returns_multi()`**
  - Realized put column uses the same put-spread PnL: long ATM, short OTM; BS entry/exit with chain IV; spread value and return from `p_spread_entry`.

- **backtest.py — `_solve_markowitz()`**
  - Put-spread sleeve (index `3*i+2`) remains capped by `max_put_weight` from dynamic hedge sizing; `w_call + w_put <= max_option_weight` unchanged.

## (2) Scenario optimizer: CVaR on relative loss (portfolio − benchmark)

**Goal:** Penalize CVaR of *relative* losses vs benchmark so “going to cash” cannot dominate by minimizing absolute tail loss.

- **opt/scenario_opt.py — `solve_scenario_cvar()`**
  - **Benchmark:** Single-asset (n_assets == 4): `bench = R[:, 0]`. Multi-asset: `bench = mean(R[:, eq_indices], axis=1)` with `eq_indices = [0, 3, 6, ...]`.
  - **Relative return:** `rel_rets = (R @ w) - bench`; loss for CVaR: `loss_i = -rel_rets_i`.
  - Rockafellar–Uryasev: same `t_var`, `u`; constraints `u >= -rel_rets - t_var`, `u >= 0`.
  - Objective unchanged: maximize `expected_ret - lambda * CVaR_alpha(relative loss) - tcost - small L2 reg`.
  - Diagnostics added: `cvar_relative_model`, `cvar_relative_empirical`, `bench_mean`, `mean_rel_scenario_port` (and kept `cvar_model`/`cvar_empirical` as the relative values for compatibility).

## (3) Markowitz equity μ: steadier (anchor + stronger shrink + clip)

**Goal:** More stable equity expected return so option μ does not dominate.

- **config.py**
  - `MU_CLIP_EQUITY = (-0.03, 0.03)` (per-period, consistent with REBALANCE_DAYS).
  - `EQUITY_PREMIUM_ANNUAL_ANCHOR = 0.04` (prior for equity sleeve).
  - `MU_SHRINKAGE_EQUITY = 0.75` (stronger shrink for equity toward prior).

- **backtest.py — Markowitz branch**
  - `mu_prior_equity = r_period + (EQUITY_PREMIUM_ANNUAL_ANCHOR or 0.04) * (REBALANCE_DAYS/252)`.
  - For equity indices: `mu_t[equity] = (1 - MU_SHRINKAGE_EQUITY)*mu_roll[equity] + MU_SHRINKAGE_EQUITY*mu_prior_equity`, then clip to `MU_CLIP_EQUITY`.
  - Options keep existing shrinkage to cash; USDOLLAR μ = r_period.

## (4) Transparency logging after cold start

**Goal:** Debug/INFO prints every K periods after warm-up, without printing the first N periods.

- **config.py**
  - `PRINT_DIAGNOSTICS = True`, `PRINT_EVERY = 5`, `PRINT_START_PERIOD = 8` (aligned with MIN_PERIODS_FOR_ROLL).

- **backtest.py**
  - When `t >= PRINT_START_PERIOD` and `(t - PRINT_START_PERIOD) % PRINT_EVERY == 0` and `PRINT_DIAGNOSTICS`:
    - **Markowitz:** date, μ_t, ρ, μ_wc, r_cash, diag(Sigma_wc), per-asset Sharpe-like `(mu_wc - r_cash)/sqrt(diag(Sigma_wc))`, w_opt, max_put_weight; and CM-IEWMA expert weights when available.
    - **Scenario:** date, tactical_put_weight, tactical_reason, mean(port), mean(bench), mean(relative), cvar_relative_model, cvar_relative_empirical, w_opt.

## (5) CM-IEWMA combiner (replace fixed SIGMA_IEWMA_WEIGHT blend)

**Goal:** Combine RND covariance with a CM-IEWMA expert mix instead of a single fixed IEWMA weight.

- **config.py**
  - `RND_BLEND_WEIGHT = 0.3` (fraction of Σ from RND; 70% from IEWMA).
  - `CMIEWMA_TEMPERATURE = 1.0` (softmax temperature for expert weights).

- **data/covariance.py — `CMIEWMAPredictor`**
  - `temperature` parameter in `__init__`; used in `_score_weights` for softmax(scores / temperature).
  - `predict_all()` returns list of candidate Sigmas; `get_last_weights()` returns weights used in last `predict()` for logging.

- **backtest.py**
  - `Sigma_t = (1 - RND_BLEND_WEIGHT)*Sigma_iewma_cm + RND_BLEND_WEIGHT*Sigma_rnd` (Sigma_iewma_cm is the existing weighted combination from CMIEWMAPredictor).
  - CMIEWMAPredictor instantiated with `temperature=CMIEWMA_TEMPERATURE`.
  - Expert weights logged at the same cadence as diagnostic prints.
